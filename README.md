# Ship Before Ready

Plugin de Claude Code que lleva a un builder de su idea a sus primeros leads antes de escribir código: tres preguntas, una landing publicada, tres guiones de video, lectura de números y un veredicto.

Todo corre en las cuentas del builder: su repo, su Claude, su Vercel y su PostHog.

## Instalación

```
/plugin marketplace add jrodolforojas/ship-before-ready
/plugin install ship-before-ready@ship-before-ready
```

## Skills

| Comando | Qué hace |
|---|---|
| `/ship-before-ready:conectar` | Verifica las cuentas del builder. |
| `/ship-before-ready:interrogar` | Produce el brief. |
| `/ship-before-ready:reglas` | Sella las varas y la fecha de veredicto. |
| `/ship-before-ready:landing` | Genera y publica la landing. |
| `/ship-before-ready:guiones` | Escribe tres guiones con link rastreado. |
| `/ship-before-ready:veredicto` | Lee los números y da el veredicto. |

Estado: en construcción. Las skills son marcadores por ahora.
